# cloude-video-

Video unboxing popcorn 1 kilo RM18 dengan motion graphics & hook jualan.

- `assets/original.mp4` – video asal
- `output/popcorn_hook.mp4` – video siap (animasi + SFX)
- `render.py` – skrip yang menjana output

Jana semula: `python3 render.py assets/original.mp4 output/popcorn_hook.mp4` (perlu ffmpeg, numpy, pillow)
